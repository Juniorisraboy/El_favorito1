
# 🌐 Página Web El Favorito

## 📌 Descripción del proyecto

El Favorito es un proyecto de desarrollo web que consiste en la creación de una página web con fines de revisión y evaluación. Su objetivo es poner en práctica los conocimientos adquiridos en programación y diseño web.

## ⚙️ Tecnologías utilizadas

- HTML5

## 🚀 Instalación y uso

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Localizar el archivo `index.html`.
4. Abrir el archivo en un navegador web para visualizar la página.
